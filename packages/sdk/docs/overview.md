# sdk

Runtime-agnostic TypeScript SDK for the Orun QA control plane API

A shared package of the orun-qa workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Orun QA control plane API
- **web-console-next** — Next.js 15 + opennextjs/cloudflare delivery of the Orun QA web console (per-environment, Workers + Static Assets)
